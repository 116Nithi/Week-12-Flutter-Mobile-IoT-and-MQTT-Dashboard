# Week 12: ผลที่คาดว่าจะได้ (Lab 12.1 - 12.4)

> **สถานะ: ผลที่คาดว่าจะได้ ยังไม่ได้ทดสอบกับมือถือ บอร์ด หรือ Broker จริง**
> ทุกค่าเป็นการคาดการณ์จากโค้ดและใบงาน ต้องทดลองจริงแล้วนำผลมาแทน

## ก่อนรัน

- รัน Mosquitto ด้วย `mosquitto.conf` ของ repo นี้
- ถ้ารันบนมือถือจริง ให้ใส่ IP ของคอมพิวเตอร์ที่รัน Broker ห้ามใช้ `127.0.0.1`
- **เฟิร์มแวร์ Lab 12.4:** แก้ `WIFI_SSID`, `WIFI_PASS` และ `MQTT_BROKER_URI` ค่าเดิมเป็นเครือข่ายของคนอื่น
- เครื่องนี้ยังไม่มี Visual Studio จึงรันแอปเป็น Windows Desktop ไม่ได้ ให้รันบน Android

## Lab 12.1: MQTT Basics

- ใส่ IP แล้วกดเชื่อมต่อ สถานะเปลี่ยนจาก `กำลังเชื่อมต่อไปยัง Broker...` เป็นเชื่อมต่อสำเร็จ
- แอป Publish และ Subscribe ข้อความกับ `mosquitto_sub` และ `mosquitto_pub` ได้

## Lab 12.2: Actuator Switch

- แตะสวิตช์แล้วส่งคำสั่งไปยัง `iot/esp32/control`
- สวิตช์เปลี่ยนสถานะหลังได้ ACK จาก `iot/esp32/led_ack` เท่านั้น
- ส่ง `offline` แบบ Retain ไปยัง `iot/esp32/status` แล้วแอปแสดงว่าอุปกรณ์ออฟไลน์

## Lab 12.3: Telemetry Dashboard

- รัน `pyTeleSim.py` แล้วเข็มหมุนนุ่มนวลในช่วง 0.0 - 3.3 V
- กราฟเก็บประวัติไม่เกิน 30 ตัวอย่าง

## Lab 12.4: End-to-End

ตาราง Test Case กรอกในใบงานแล้วว่า "คาดว่าผ่าน (ยังไม่ได้ทดสอบ)" ส่วนตาราง RTT ใบงานระบุค่าประมาณไว้แล้ว: Local Wi-Fi 20 - 60 ms และ 4G 80 - 250 ms

## สิ่งที่แก้ในโค้ด

เปลี่ยน `sdk: ^3.13.1` เป็น `^3.12.0` ใน `pubspec.yaml` ทั้ง 4 แอป เพราะเครื่องนี้ใช้ Flutter 3.44.4 (Dart 3.12.2) และ `flutter pub get` ไม่ผ่านด้วยค่าเดิม ถ้าอัปเกรด Flutter แล้วจะเปลี่ยนกลับก็ได้

แก้บั๊กในแอป: เมื่อปิดหน้าจอระหว่างเชื่อมต่อ MQTT แอปจะเรียก `setState` หลังหน้าจอถูกทำลายและเกิด Error จึงยกเลิก `onDisconnected` ก่อน `disconnect()` และเช็ก `mounted` ก่อน `setState`

แก้ `test/widget_test.dart` ของ Lab 12.1 และ 12.2 เพราะไฟล์เดิมเรียก `MyApp` ที่ไม่มีอยู่จริง ตอนนี้ `flutter test` ผ่านทั้ง 4 แอป แต่ยังไม่ได้ build เป็น APK หรือรันบนมือถือจริง
